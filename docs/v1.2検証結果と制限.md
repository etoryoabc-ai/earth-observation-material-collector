# v1.2 原因調査・検証結果・制限

## 0件と155シーンの原因調査

現行v1.1系ソースの確認で、初期選択がキー必須のPexels/Pixabayのみ、キー不要のCommons/NASAが既定対象外であること、全検索がエラーでも最後に一律「検索完了」と設定することを確認しました。また、文・空行・生物名・年代・仮説区分の変化で頻繁に切る分割ロジックでした。

これらは0件や過分割につながり得るコード上の原因です。ユーザーのWindows保存設定・通信ログ・実原稿がないため、ユーザーの147不足/155シーンの実行で何が発生したかをすべて断定していません。

## 実検索（模擬なし）

開発Linux環境のネットワーク設定で素材APIホストの許可がないことを確認。公式Commons/NASAへの実接続を試し、接続/応答エラーと試験用要求予算への到達を記録しました。

`docs/evidence/v1.2-live-local.json` は実通信試験です。模擬応答は使用していません。ラッコ/ケルプの候補は0件で、**実素材収集の成功は未検証・未達** です。NASAのoceanは接続確認用クエリであり、ラッコ原稿の代用ではありません。制限回避や他環境をプロキシとして用いた素材取得は行っていません。

ユーザーの完成原稿は未提供のため、原稿による実証は未実施です。独自の短文や模擬データを完成原稿として報告していません。

- 二段階解析、原稿の完全再結合、位置一致、見出しのみのシーン抑止、長文の過分割防止。
