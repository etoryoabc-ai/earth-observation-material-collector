# 地球の観察録 v1.2 使用説明書

## 起動・更新

1. 新しいZIPを旧版とは別の書き込み可能なフォルダへ「すべて展開」します。
2. Python 3.12がある状態で、起動.batをダブルクリックします。追加パッケージやコマンド入力は不要です。
3. 起動できなければ診断.batをダブルクリックします。Python・検索先の設定状態を表示し、logsフォルダにログを残します。キーの値は表示しません。診断.batは通信や原稿・dataの変更を行いません。
4. 旧データを引き継ぐときはアプリを終了し、旧dataフォルダとsettings.local.jsonをコピーします。コピー先に既存データがある場合は先にバックアップし、上書きしないでください。

起動・テスト・診断バッチはASCII・BOMなし・CRLFに固定しています。日本語パス・空白を扱うv1.1.1の起動構造を維持。Python Launcherの3.12を優先し、PATHのPython 3.12へフォールバックします。正常終了・エラー時は画面を一時停止します。Python起動後の説明は日本語です。

## 原稿を読み込む

TXT/Markdown（UTF-8/BOM/Shift-JIS）を選択して新規プロジェクトを作ります。旧プロジェクトをv1.2で再解析する場合は「旧原稿をv1.2で新規解析」を使います。元のプロジェクトと採用状態はそのまま残り、新規プロジェクトへ原稿だけを引き継ぎます。

解析は「文単位の記録→映像シーン」の二段階です。各文の地名・生物・年代・仮説/観察の記述と原稿位置を保存し、映像テーマの継続・転換と場所・章の境界を使ってまとめます。段落や動物名が変わるたびに分割せず、固定文字数・固定シーン数にも合わせません。

見出し・動画タイトルは本文側へ保持し、それだけを検索シーンにしません。タイトル中だけの地名・生物を本文の検索条件に混入させません。文脈の指示語について候補を記録する場合も「推定・要確認」とし、明示された地名や年代とは別欄です。研究事実や因果の真偽を自動確定する機能ではありません。

「次のシーンと結合」で結合、「シーン編集→映像シーンを分割」で原稿の位置をクリックして分割できます。検索後でも利用できます。採用・取得済み素材は削除しません。分割した元シーンの素材は先頭側へ保持し、カードに再確認の案内を出します。「確認・採用」の対応シーンで割当を変更できます。原稿全文・順序・位置の一致を編集時も検査します。

## 検索サイトを確認

キーなしの初期検索先は **Wikimedia Commons と NASA** です。旧版のPexels/Pixabayのみという初期設定も、キー不要の設定に移行します。Pexels/Pixabayの無料キーを保存すると、自動的に検索対象へ追加します。

「API設定・素材サイト」で対応・未対応、キーの必要有無、選択状態を確認できます。検索先が有効でなければ検索前に停止して案内します。サイトの選択が有効でも通信成功を保証しません。「実API接続確認」でネットワーク状況を確認できます。

NOAA / USGS / National Park Serviceは本版の自動検索 **未対応** です。公式資料入口への手動リンクのみ提供します。公的機関に掲載されていることを自由利用の根拠にはしません。

## 検索する

検索前に原稿文字数・章数・文単位数・映像シーン数・有効サイト・最大要求見積と予算を表示します。要求見積は上限で、目標到達や提供元上限で早く停止するため、実通信数とは異なります。

「検索開始・再開」を押します。実素材を探すときは「模擬テスト」を外してください。動画6件・写真3件を初期目標に、日本語・英語・生物別・学名・同義語・一般映像・広域地名へ探索します。長い原稿でシーン当たり予算が少ない場合は、英語を優先して各シーンの動画と写真に要求を配分します。先頭シーンに予算を集中させず、不足分は再検索で続けられます。学名を特定できない生物は推測で補いません。広域映像は指定地点での撮影と扱いません。

途中ではシーン・サイト・検索語を表示し、各応答で保存します。API上限・接続失敗があっても他のサイトは続行します。提供元ごとに1回の検索予算（初期80要求）があり、足りなければ時間を空けて再開します。検索語を編集した場合も採用済みを保持して再検索できます。

素材0件の場合は、成功と誤解する「検索完了」表示にしません。サイト別に次を表示します。

- 検索成功・候補あり / 検索成功・候補0件
- APIキー未設定 / API認証失敗
- 接続失敗 / アクセス拒否（原因は個別確認）
- API利用上限 / 今回の検索予算上限
- 検索先未対応 / 検索処理エラー / 一部のみ検索成功

最初に候補総数・動画/写真数・不足シーン・権利確認済み取得候補・次の操作を表示します。下に応答件数・検索語・エラー理由も表示します。実素材と模擬候補は別集計です。

## 内容と権利を確認して採用

候補のタイトル・タグ・説明を一次スクリーニングに使用しますが、映像の内容・撮影地・種・年代の確定証拠にはしません。関連する生物のメタデータがない候補や別種の表記などは目標件数から除外します。完全な映像内容判定はできないため、提供元での確認は必須です。

重複は提供元ID、配信URL（署名クエリの違いを除く）、同一プレビューURLで排除します。別ID・別URLの似た構図を画像内容から見分ける機能は未実装です。

NASA等で公式配信URLの取得に対応していない素材は「リンク候補」と表示します。自動保存しません。動画の形式・長さ・解像度は提供元メタデータにある範囲で表示し、未取得値を創作しません。

権利区分はA/B/C/D/Eを維持。一般サイト規約と個別素材の権利条件は別欄です。A/B、商用利用「可」、ライセンス名/URL・確認根拠・確認日・人間の最終確認が揃った採用素材だけをダウンロードします。C（引用検討）・D（未確認）・E（利用不可）と模擬素材は自動取得できません。引用の適法性は人間が確認する必要があります。

採用素材を保存した後、「レポート出力」でシーン別ファイル・出典・権利・不足理由を出力します。保存先は画面に表示します。既存ファイルの無断上書きはしません。

## レポート

従来の9種類に加え、sentence_units.csv（文単位と根拠）、source_validation.json（全文検査）、search_summary.json（サイト別状態・次の操作）、scene_metrics_real/mock.csv、search_attempts.csv、validation_report.jsonを出力します。CSVはExcel向けUTF-8 BOMです。

## 今回の実証の範囲

ユーザーの完成ラッコ原稿は開発環境に存在しません。20〜40シーンへの妥当性、原稿全章の抽出精度、各シーンの実素材充足は未検証です。同梱サンプルやテスト文を完成原稿と扱っていません。

開発環境のネットワークでは素材APIへの接続ができず、実検索検証は候補0で未成功です。詳細は「v1.2検証結果と制限.md」を参照してください。単体テストや画面の固定応答テストを実素材収集成功とは扱いません。
