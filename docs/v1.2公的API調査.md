# 公的機関の素材検索 API 調査

調査日：2026-11-01。公式文書の閲覧による調査と、実際のアプリでのAPI接続成功は別です。

|提供元|公式資料|本版|
|---|---|---|
|Wikimedia Commons|https://www.mediawiki.org/wiki/API:Imageinfo |キー不要の検索APIとimageinfo/extmetadata/metadataを実装。動画/画像を区別し、長さ等は提供データがある場合のみ記録。個別ライセンスは要確認。|
|NASA Image and Video Library|https://images.nasa.gov/docs/images.nasa.gov_api_docs.pdf |キー不要の/searchを実装。素材ページ・タイトル・説明・作成者等のリンク候補。個別ファイル取得は未対応。|
|USGS ScienceBase|https://www.usgs.gov/sciencebase-instructions-and-documentation/api-and-web-services / https://www.usgs.gov/sciencebase-instructions-and-documentation/building-search-queries |公開REST検索とJSONが存在。データセットや図表も多く、実写素材のみの抽出・権利と配信方式を検証できていないため、本版コネクターは未対応。公式リンクのみ。|
|National Park Service|https://home.nps.gov/subjects/developer/api-documentation.htm |multimedia/videos等の公式APIが存在するがAPIキーが必要。追加コネクターは未対応。キー不要とは表示しない。|
|NOAA|https://www.noaa.gov/multimedia / https://photolib.noaa.gov/ |公式素材入口を調査。今回の範囲で採用できる統一した素材検索API・許可された取得方式の検証は未完了。全素材自由利用とせず、本版の自動検索は未対応。|

公的機関の素材であっても第三者の権利があり得るため、ライセンスの一律推定はしません。スクレイピングやアクセス制限の迂回、有料APIは導入していません。
