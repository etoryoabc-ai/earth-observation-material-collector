## 合格

- 自動テスト **23件合格、失敗0件**（`python -m unittest discover -s tests -v`）。
- 原稿全文の再結合一致、文字位置、改行・絵文字・末尾改行なし・前文の保持。
- 明示地名の分離、年代・仮説の検出、未知の固有名を作らないこと。
- 段階検索、動画先行、模擬で1シーン9候補（6動画・3写真）、同一ID/URL重複除去。
- API上限後の他提供元継続、保存済み検索の再送抑制、一時停止。
- コネクター4種の応答変換（固定応答を使用）。
- 未確認・C/D/E・模擬素材の採用/取得拒否。
- HTTP操作のトークン認証、無関係なファイルの非公開、編集・分割の永続化。
- CSV BOM、CSV式注入対策、9種類の必須ファイル生成、上書きしない出力。
- 検証済み情報源を必須とするSVG生成、ラベルのエスケープ。
- 取得のRange再開、Range無視時の最初からの取得、既存ファイル保護（通信は模擬）。
- JavaScript構文チェック合格。
- Chromium の実ブラウザ操作：原稿読込→模擬検索→採用拒否→レポート出力。JavaScript実行エラー0件。デスクトップ1440px・モバイル390pxで表示を確認。

最初のテストでは候補目標の期待値を誤って10件としたため1件失敗しました。実装の停止条件（合計8以上・動画5以上・写真3以上）で9件が正しいことを確認し期待値を修正。その後、全件合格しています。通常のサンドボックスはループバックのソケット作成を制限したため、HTTPテストは許可された実行モードで行いました。
