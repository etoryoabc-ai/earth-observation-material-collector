# Windows 使用手順（v1.1）

## 1. 更新版の準備

1. 更新版ZIPを右クリックして「すべて展開」。旧版とは別のフォルダを指定します。
2. Python 3.12がなければ https://www.python.org/downloads/ からインストールします。Windows Python Launcher（py）を有効にしてください。
3. 旧版を終了します。引き継ぐ場合は旧版の `data` と `settings.local.json` を新しいフォルダへコピーします。既存のコピー先を無断で置き換えず、必ずバックアップします。
4. `起動.bat` をダブルクリック。ブラウザが開かなければ `http://127.0.0.1:8765` を開きます。

起動方法は初期版と同じです。追加パッケージ・有料契約は不要です。黒い起動画面は利用中に閉じないでください。

## 2. 無料のAPIキーを登録

1. Pexels https://www.pexels.com/api/ にログインして無料APIキーを取得します。
2. Pixabay https://pixabay.com/api/docs/ にログインして無料APIキーを取得します。
3. アプリの「API設定・素材サイト」を開き、各入力欄にキーを入力します。キーをチャットへ貼り付ける必要はありません。
4. Pexels・Pixabayにチェックがあることを確認し「API設定をローカル保存」。画面の入力値は消えますが、設定は保存されています。空欄で再保存しても既存キーは消えません。
5. 「実API接続確認」を押します。各サービスの動画・写真APIを確認します。

表示の読み方：

- 「実API応答成功 n件」：実際に公式APIへ接続し、応答を取得しました。0件の場合も検索の応答は正常ですが素材が見つかったとは意味しません。
- 「APIキャッシュ取得 n件」：過去24時間以内の応答です。今回の新規通信成功とは別です。
- 「キー未設定」「HTTP401/403」「API上限」等：実検索の成功ではありません。エラー原因を解消してください。

環境変数に古いキーが設定されている場合は環境変数が優先されるため、そちらの設定を確認してください。学校・会社等のネットワークでは api.pexels.com / pixabay.com と各配信先へのHTTPSアクセスが必要です。アクセス制限を迂回しません。

## 3. 実際のラッコ原稿で収集

1. 完成した原稿のTXTまたはMarkdownを選択し、「新規プロジェクト」。**同梱の「模擬テスト原稿.md」は本物の完成原稿ではありません。**
2. シーン一覧から原稿と根拠を確認します。とくにアダック島・1987/1997年・仮説・バンクーバー島・サンニコラス島を確認してください。
3. 取りこぼしがあれば「シーン編集」で素材指示や日本語検索語を修正します。英語検索フレーズを1行1件で追記できます。例：`Adak Island kelp forest`。一般映像の例 `underwater kelp forest` は指定地の実記録として扱わないでください。
4. 必要なら検索前に手動分割します。原稿位置は0始まりのPython文字単位です。
5. **「模擬テスト」を外したまま**「検索開始・再開」。動画を先に、日本語・英語・学名・関連語・別サイトで検索します。
6. 一時停止しても保存されています。再起動後は「続きから開く」→「検索開始・再開」。API上限時は表示に従って時間を空けて再開します。

初期目標は6動画＋3写真。素材がないときは無関係な候補で埋めることを目標とせず、低一致候補は見送りにしてください。件数と割合は保証値ではありません。

## 4. 内容と権利を確認して採用

1. 「提供元で確認」で実映像を確認します。サムネイルやタイトルだけで断定しないでください。
2. 「確認・採用」で、撮影地・生物種・年代・行動・一般映像か実記録かを記録します。
3. 一般規約の商用条件と、素材固有の肖像・商標等の条件を別々に確認します。一般規約が無料でも個別素材が未確認なら初期Dのままにします。
4. 利用可能なら権利A/B、商用利用「可」、ライセンス名/URL、条件、確認根拠を記録し、人間の最終確認にチェックして採用します。
5. C（引用検討）は必要性・原稿部分・範囲・区別・出典表示・主従関係を記録できますが、自動採用・取得しません。D/Eも採用できません。
6. 無関係な候補は「見送り」。その後「不足分を再検索」で採用済みを維持して補充します。
7. 「採用素材を保存」で必要分だけダウンロード。失敗時は素材カードの理由を確認し再試行します。

## 5. 収集数と動画比率を検証

「シーン別の実検索・模擬検索の集計」を開きます。

- 実候補数・動画数・写真数・動画率
- 一般映像の数（指定地の撮影を保証しない）
- 人間が確認した高関連度の数
- 実API応答・キャッシュ取得の件数
- 不足理由・代替案

候補数が多くても、高関連度が未確認なら「原稿に一致する映像が揃った」と判断できません。実際に選べる素材を確認してください。

「レポート出力」を押すと保存先を画面に表示します。エクスプローラーでその場所を開きます。

- `summary_report.md`：結果一覧
- `scene_metrics_real.csv`：本番原稿の実候補数と動画比率
- `scene_metrics_mock.csv`：模擬データだけの結果
- `missing_assets.csv`：不足と理由
- `search_attempts.csv`：検索語・提供元・応答の出所
- `license_report.csv`：権利条件と確認記録
- `sources.md`：説明欄に使う採用素材の出典
- `scene_001` 等：保存済み素材

CSVはExcel対応のUTF-8 BOMです。Windows実機での最終動作確認はまだ行っていません。問題が出た場合はキーを含めず、起動画面のエラーや該当レポートを共有してください。
