# 地球の観察録｜素材収集・確認ツール v1.1.1

Windows起動修正版：[配布ZIP](downloads/earth-observation-material-collector-v1.1.1.zip) / [修正内容と手順](docs/v1.1.1起動修正.md)。バッチをASCII・CRLFに固定し、起動診断ログを追加しました。

独立した Windows 11 / Python 3.12 用ローカルアプリです。起動.bat と既存の採用画面を維持しています。Python標準ライブラリのみで動作し、有料サービス・有料API・AI解析を呼び出しません。

**公式APIを呼ぶ実装と、そのAPIで実素材を取得できたという検証結果は別です。** 今回はAPIキーと実際のラッコ完成原稿が未提供のため、実APIによる収集成功・本番原稿の収集数は未検証です。キー未設定時はその理由を表示し、模擬データで補いません。

具体的な操作は [Windows使用手順](docs/Windows使用手順.md)、結果は [v1.1検証結果](docs/v1.1検証結果.md) を参照してください。

## 起動と更新

1. ZIPを「すべて展開」。初期版とは別のフォルダへ展開してください。
2. Python 3.12をインストール済みなら `起動.bat` をダブルクリック。
3. `http://127.0.0.1:8765` がブラウザに開きます。追加パッケージは不要です。
4. 既存データを使う場合はアプリを終了し、旧版の `data` フォルダを新版へコピーします。既存フォルダがあれば上書きせず先にバックアップしてください。キー設定も旧 `settings.local.json` をコピーできます。
5. 「API設定・素材サイト」で無料キーを入力→ローカル保存→実API接続確認。
6. 完成原稿TXT/Markdownを読み込み、シーンを確認して「検索開始・再開」。模擬チェックは外します。
7. 実写を提供元で確認し、利用条件と関連度を記録→採用→保存→レポート出力。

画面からのキー保存は `settings.local.json` のみです。キー値を画面へ返さずGitにも含めません。環境変数 PEXELS_API_KEY / PIXABAY_API_KEY があれば優先します。APIキーは共有しないでください。アプリは127.0.0.1にだけ接続待ち受けします。

## v1.1の主な変更

- Pexels公式APIの動画・写真、Pixabay公式APIの動画・写真を認証付きで呼び出す処理を強化。無料キーは画面から設定可能。設定直後に反映。
- 初期検索先は Pexels / Pixabay。Commons / NASA は必要なら画面で追加。NOAA・USGS・NPSは従来通り手動リンク。
- 動画を先に探索。日本語→英語→生物別・学名・表記違い→同じ生物や風景の一般映像へ拡張。複数生物をひとつの長い検索語に結合するだけで終わらない。
- 動画6件・写真3件（66.7%）が初期の探索目標。最低不足判定は動画5件・写真3件・合計8件。件数や割合の保証ではありません。
- 各応答から少量ずつ取り込み、別サービスも探索。日本語候補で埋まっても英語動画検索を1段階確認。種が違うことを示す一部の明示表記は除外扱い。
- 見送り・権利E・メタデータ相違を候補目標から除外。「不足分を再検索」で既存採用は維持し、同じ素材を重複登録せず残りを探索。
- 文ごとに生物・地名・年代・仮説/記録・必要映像を抽出し、原稿内の根拠位置も保持。英語・学名・別表記対応を追加。シーン編集で英語検索フレーズを追記可能。
- 原稿に書かれた調査年と素材の撮影年を混同しない。文脈から推測した場所・年代を自動確定しない。
- Pexels/Pixabayの一般ライセンス、商用利用条件、改変・表示・禁止用途、確認根拠を記録。素材固有の権利確認とは別欄。
- API応答とAPIキャッシュと模擬データを区別。シーン別件数・動画率・一般映像数・確認済み高関連度数・不足理由を表示/出力。
- 24時間キャッシュ、429の待機期限保存、提供元別要求予算（初期80回/実行）、Pexelsのローカル時間枠予算を追加。HTTP400の検索条件エラーは他の英語クエリを止めない。

## 原稿・関連度の注意

対応入力はTXT/Markdown（UTF-8/BOM/Shift-JIS）、原稿全文は変更せず保存します。位置はPython文字単位・0始まり・終了位置は範囲外。規則解析であり、意味理解を網羅するLLMではありません。

ラッコ・ウニ・ケルプ・シャチなどの辞書、指定4地域と一部広域地名に対応します。未知の名前・代名詞・研究因果の自動検証はできません。ウニやケルプは種が不明なまま学名を断定しません。シーン境界は明示された場所・生物・年代・仮説の変更や段落を手掛かりにします。旧プロジェクトの解析内容を無断上書きしないため、v1.1解析を利用する場合は原稿を新規読込してください。

候補のタイトル・タグを映像内容の確認済み証拠にはしません。すべて初期関連度は要確認です。一般映像は指定撮影地の実記録として扱いません。低関連度候補は見送りにして補充してください。似た構図の別ID映像の視覚重複検出はありません。

## 権利・取得

A：無料条件確認済み / B：条件付き / C：引用検討 / D：未確認 / E：利用不可。

Pexels/Pixabayの一般ライセンスに商用許可があっても、個別素材の初期商用利用は「要確認」、初期リスクはDです。第三者権利・人物・商標・用途を人間が確認して記録してください。採用にはA/B・商用利用「可」・ライセンス名/URL・確認根拠・確認日・最終確認が必要です。C/D/E・模擬素材は採用/取得を拒否します。引用には必要性・対応原稿・範囲・区別・出典・主従関係の記録欄がありますが、適法性は自動確定しません。

採用済みだけ公式配信先からダウンロード。HTTPS・公式ホスト・公開IP・転送先を検査し、失敗時は3回再試行します。ETag等の検証子付き途中ファイルはRange再開。再開が安全にできない場合は先頭から取得。既存ファイルを上書きしません。上限2GiB/ファイル。期限切れ配信URLの自動更新は未実装です。

## 出力

`data/<プロジェクトID>/` に原稿・候補・採用状態、`media/scene_001/` に採用素材を保存。

「レポート出力」は `exports/<日時>/` に毎回新規作成します。

- 従来9種：scene_list.csv / asset_candidates.csv / review.html / download_manifest.csv / license_report.csv / sources.md / missing_assets.csv / slide_requests.csv / summary_report.md
- v1.1追加：scene_metrics_real.csv / scene_metrics_mock.csv / search_attempts.csv / validation_report.json
- 全状態：project_snapshot.json
- シーンフォルダ：保存済み採用素材と生成済みSVGのコピー

CSVはUTF-8 BOM。式として解釈される文字列は先頭を保護します。正確な元原稿はJSONに保持します。summary_report.mdは動画率と不足理由を一覧表示。接続確認の結果は `data/connection_check.json`。模擬のAPI応答は実検索成功に数えません。

## 無料図解・対象外

検証済み情報源を入力してSVG関係図を作成できます。数値や座標は自動補完しません。自動地図・数値グラフ・PNG・動画編集・DaVinci Resolve自動配置は対象外です。

## テスト

`テスト.bat` をダブルクリック。開発用：`python -m unittest discover -s tests -v`。通常利用にはコマンド不要です。

テストの固定API応答とブラウザの模擬検索は、実API収集実績とは別物です。本版は37件の自動テストとChromium操作を確認しました。Windows実機と完成ラッコ原稿の実検索は未検証です。
