# 地球の観察録｜素材収集・確認ツール v1.2

[Windows用ZIP](downloads/earth-observation-material-collector-v1.2.zip) · [日本語使用説明書](docs/v1.2使用説明書.md) · [原因調査・検証結果・制限](docs/v1.2検証結果と制限.md)

起動.batをダブルクリックし、原稿読込→検索先確認→検索→素材確認→採用→保存の順に操作します。Python 3.12が必要です。有料APIは使用しません。キーなしでもCommons/NASAを既定の検索先にします。

v1.2は文の解析と映像シーンのグループ化を分離。見出しだけの検索シーンを作らず、結合・分割・割当変更が可能です。検索後も原稿と採用素材を保持します。0件・失敗・正常な0件応答・一部成功を区別し、次の操作を表示します。

**完成ラッコ原稿は開発環境に未提供です。実接続試験では開発環境のネットワーク制限で候補を取得できていません。単体・画面テストの成功を実素材収集の成功とは扱いません。** シーン数や各シーン9候補の充足は保証しません。

更新は旧版と別フォルダへ「すべて展開」。引き継ぐ場合はアプリを終了し、旧dataとsettings.local.jsonをバックアップしてからコピーしてください。旧プロジェクトは保持し、「旧原稿をv1.2で新規解析」で元原稿だけを新規解析できます。

診断.batでPythonと設定状態を確認できます。APIキーの値は出力しません。個別素材の権利は人間の確認が必要です。詳細は使用説明書を参照してください。

## 出力と権利

シーン一覧・全候補・取得状況・権利・出典・不足・図解指示・概要の9種類に、文単位記録と全文検査、実/模擬の集計、サイト別結果、検索履歴を追加します。CSVはUTF-8 BOM。採用済みで条件確認済みの素材のみ公式配信先から保存します。引用の適法性は自動確定しません。

## テスト

`テスト.bat` をダブルクリック。開発用は `python -m unittest discover -s tests -v`。固定応答・画面テストと、実ネットワークの検証結果は別々に報告します。Windows 11実機のExplorer操作は未検証で、Windows Serverの自動テストとは区別します。

自動地図・数値グラフ・動画編集、映像内容AI、NOAA/USGS/NPS自動素材検索は未実装です。NASAはリンク候補で、自動ファイル取得に対応しません。詳細は検証結果の対応表を参照してください。
